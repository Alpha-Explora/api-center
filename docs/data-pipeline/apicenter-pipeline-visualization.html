APICenter Multi-Tribe Data Pipeline

A governed test and prod event pipeline for tribe-owned events, shared-service telemetry, APICenter control-plane events, S3 landing, Athena validation, and management visibility.

North Star
From tribe request to gateway decision to event export to visualization, trace who called what, whether it was allowed, what happened, how much it cost, and where the data landed.

1. Producers

Tribe services

Each tribe owns domain events and payload meaning.

Shared services

Payment, email, SMS, Google auth, OTP, and geo emit platform telemetry.

APICenter control plane

Gateway, registry, auth, audit, cost, and policy events.

2. Governed Publish

SDK + Gateway

  • Authenticates tribe principal
  • Checks consumes/scopes
  • Adds source service attribution
then

Event envelope

tribeId, sourceServiceId, eventType, payload, metadata, environment.

3. Topics

Test topics

Used for onboarding, smoke tests, and pipeline validation.

Prod topics

Used only after approval, prod ownership, and access controls.

Topic families

Tribe events, shared-service events, APICenter governance events.

4. Landing

Confluent S3 Sink

Flushes governed Kafka topics into raw S3 by physical topic.

writes

S3 Raw

api-center-raw-data/topics/<physical_topic>/year/month/day/hour

Raw is platform-only

BI and tribe readers do not get raw topic bucket access.

5. Catalog + Transform

Glue + Athena raw table

Projected partitions over approved physical topics.

Bronze

Parse, unwrap, validate, normalize, and mark quality status.

Silver + Gold

Common Silver for cross-tribe standards; Tribe Silver/Gold for local semantics.

6. Consumption

Management visibility

Pipeline health, traceability, audit, costs, access review.

Tribe analytics

Approved tribe dashboards and BI read curated Silver/Gold only.

Athena results

api-center-athena-results split by platform, management, tribe, and environment.

Central Governing Tribe Owns

  • Topic standards and event envelope.
  • Gateway authorization and publish governance.
  • Raw landing, catalog, Bronze, common Silver.
  • Workgroups, result bucket, access review, cost controls.

Each Tribe Owns

  • Domain event schemas and event meaning.
  • Payload quality at source.
  • Tribe Silver/Gold semantic models.
  • Tribe dashboards, KPIs, and decisions.
