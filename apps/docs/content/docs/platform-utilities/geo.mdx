---
title: "Geocoding and geofencing"
description: "Geocode addresses, reverse-geocode coordinates and check whether a point is inside a geofence."
---

Turn addresses into coordinates and back, and check whether a point is inside a geofence. Results come from APICenter's geocoding provider, cached, with a local fallback.

For a Node.js backend, use the typed `api.geo` methods from the [APICenter SDK](/guides/sdk-usage). The REST reference below documents the same API for other runtimes.

---

## At a glance

- **Base Route**: `/api/v1/shared/geo`
- **Required Header**: `Authorization: Bearer <application key>` (`ak_test_…` or `ak_live_…`; see [Authentication](/guides/authentication))

---

## 1. Geocode Address

- **Endpoint**: `POST /api/v1/shared/geo/geocode`

### Request Body (`GeocodeRequest`)

```json
{
  "address": "Ayala Center, Makati City, Philippines",
  "language": "en",
  "region": "ph"
}
```

### Response (`GeocodeResponse`) — `200 OK`

```json
{
  "success": true,
  "data": {
    "formattedAddress": "Ayala Center, Makati, Metro Manila, Philippines",
    "latitude": 14.5519,
    "longitude": 121.0253,
    "components": {
      "barangay": "San Lorenzo",
      "city": "Makati",
      "region": "Metro Manila",
      "postalCode": "1223",
      "country": "PH"
    },
    "precision": "exact"
  }
}
```

Use `components` for the parts of the address and `precision` for how exactly the coordinates locate it (`exact`, `street`, `area` or `approximate`). A part the source does not know is left out.

**Deprecated, removed after 2027-03-01:** responses still carry `placeId`, `types`, `provider` and `raw`, the geocoding source's own values, with `Deprecation` and `Sunset` headers. Do not build on them.

## 2. Reverse Geocode Coordinates

- **Endpoint**: `POST /api/v1/shared/geo/reverse-geocode`

### Request Body (`ReverseGeocodeRequest`)

```json
{
  "latitude": 14.5995,
  "longitude": 120.9842,
  "language": "en"
}
```

### Response — `200 OK`

```json
{
  "success": true,
  "data": {
    "formattedAddress": "Manila, Philippines",
    "latitude": 14.5995,
    "longitude": 120.9842,
    "components": { "city": "Manila", "region": "Metro Manila", "country": "PH" },
    "precision": "approximate"
  }
}
```

`resultType` and `locationType` are deprecated: they are honoured until 2027-03-01 and ignored after.

---

## 3. Check Geofence Boundaries

- **Endpoint**: `POST /api/v1/shared/geo/geofence/check`

### Request Body

```json
{
  "latitude": 14.5995,
  "longitude": 120.9842,
  "fenceId": "metro-manila"
}
```

### Response — `200 OK`

```json
{
  "success": true,
  "data": {
    "inside": true,
    "distanceDetails": [
      {
        "fenceId": "metro-manila",
        "name": "Metro Manila",
        "inside": true,
        "distanceMeters": 0,
        "radiusMeters": 50000
      }
    ],
    "provider": "local"
  }
}
```
