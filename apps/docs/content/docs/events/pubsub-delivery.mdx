title: "Google Pub/Sub Event Delivery"
description: "Asynchronous webhook and event delivery platform architecture."
---

APICenter delivers asynchronous state change events (such as `payment.checkout.paid` or `payment.refunded`) via **APICenter-owned Google Pub/Sub**.

---

## Delivery Mechanism

1. **Outbox Pattern**: `apps/payments` writes event payloads to `shared_payment_outbox` transactional tables.
2. **Pub/Sub Dispatcher**: Published to GCP Pub/Sub topic `apicenter.payment-events.test` or `apicenter.payment-events.live`.
3. **Consumer Subscriptions**: Google Pub/Sub pushes HTTPS requests directly to consumer service Cloud Run endpoints with **GCP OIDC Bearer tokens**.

## Retries & Dead Letter Queue (DLQ)

- **Max Attempts**: 20 retries over 24 hours.
- **Dead Letter Topic**: `apicenter.payment-events.{env}.dead-letter`.
- **Manual Replay**: Available through APICenter Management Console (`apps/management`).
