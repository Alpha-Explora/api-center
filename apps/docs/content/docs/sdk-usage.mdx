The `@alpha-explora/apicenter-sdk` package provides TypeScript clients for the
public payments API and shared services.

## Install

```bash
npm install @alpha-explora/apicenter-sdk
```

## Payment API

Payment routes use a payment API key issued for a registered consumer service
and environment:

```typescript
import { PaymentsClient } from "@alpha-explora/apicenter-sdk";

const payments = new PaymentsClient({
  baseUrl: process.env.APICENTER_URL!,
  apiKey: process.env.APICENTER_PAYMENT_API_KEY!,
});

const checkout = await payments.createCheckout(
  {
    referenceId: `REF-${Date.now()}`,
    amount: { amountMinor: 49900, currency: "PHP" },
    successUrl: "https://app.example.com/success",
    cancelUrl: "https://app.example.com/cancel",
  },
  { headers: { "Idempotency-Key": `checkout-${Date.now()}` } },
);
```

## Shared Services

Shared-service routes use a service token minted from the calling service's
ID, environment, and environment secret. Its project and tribe are read from
the registered service placement:

```bash
curl -X POST "$APICENTER_URL/api/v1/auth/token" \
  -H "Content-Type: application/json" \
  -d "{\"serviceId\":\"orders-api\",\"environment\":\"test\",\"secret\":\"$APICENTER_SERVICE_SECRET\"}"
```

Pass the returned `data.accessToken` as `Authorization: Bearer <token>`. The
SDK's shared-service client accepts it as `serviceToken`:

```typescript
import { SharedServicesClient } from "@alpha-explora/apicenter-sdk";

const shared = new SharedServicesClient({
  baseUrl: process.env.APICENTER_URL!,
  serviceToken: process.env.APICENTER_SERVICE_TOKEN!,
});

await shared.emailSend({
  to: "person@example.com",
  subject: "Welcome",
  text: "Your account is ready.",
});
```
