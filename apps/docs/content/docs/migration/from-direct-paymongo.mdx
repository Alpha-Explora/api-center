---
title: "From Direct PayMongo"
description: "Migrate direct provider integrations into APICenter."
---

Move provider access behind APICenter without changing your application’s domain references or customer return flow.

## 1. Replace the boundary

Register the backend service in Management, then replace direct PayMongo calls with the APICenter SDK or the documented `/api/v1/payments/*` routes. Keep your existing `referenceId`, order IDs, and success/cancel URLs. For TypeScript, the SDK exposes methods such as `api.payments.checkouts.create(...)` and `api.payments.intents.create(...)`.

## 2. Move credentials

Configure the service ID, environment, and APICenter service secret in the consumer backend's secret manager. If a payment API key is provisioned, store it there as well. After APICenter traffic has been verified, remove the consumer's direct PayMongo credentials. Provider credentials belong to the APICenter payment runtime.

## 3. Make events authoritative

A redirect or synchronous provider response is not a final business decision. Project payment state from `payment.checkout.paid`, `payment.checkout.failed`, refund, and subscription events. Store the event ID and aggregate version for duplicate suppression and ordering checks.

## 4. Cut over deliberately

Run test traffic first and compare normalized resources and event projections. Then enable the APICenter adapter behind the service's rollout flag. Coordinate the live cutover and direct-provider secret removal with the APICenter platform team.
