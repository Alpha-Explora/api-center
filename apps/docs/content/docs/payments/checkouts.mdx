---
title: "Checkouts"
description: "Create hosted checkout pages and collect payments in PHP."
---

The Checkouts API allows consumer services to create provider-neutral payment checkout sessions for one-off charges. APICenter handles checkout generation, routes to the enabled payment methods, and reconciles provider webhooks.

For a Node.js backend, create a checkout with `api.payments.checkouts.create(...)` from the [APICenter SDK](/guides/sdk-usage). The REST example below is for other runtimes.

---

## At a glance

- **Base Route**: `/api/v1/payments/checkouts`
- **HTTP Method**: `POST`
- **Required Scope**: `payments:checkout:write` or a broader payment write scope
- **Requires Header**: `Idempotency-Key`

---

## Quickstart Code Example

### Request (cURL)

```bash
curl -X POST https://api.apicenter.itsandbox.site/api/v1/payments/checkouts \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: chk-idem-20260729-001" \
  -d '{
    "referenceId": "ORDER-991204",
    "amount": {
      "amountMinor": 49900,
      "currency": "PHP"
    },
    "successUrl": "https://app.example.com/checkout/success",
    "cancelUrl": "https://app.example.com/checkout/cancel",
    "metadata": {
      "customerId": "cust_12345",
      "tier": "pro"
    }
  }'
```

### Response Payload (`201 Created`)

```json
{
  "success": true,
  "data": {
    "checkoutId": "chk_8f1a2b3c4d",
    "referenceId": "ORDER-991204",
    "status": "pending",
    "amount": {
      "amountMinor": 49900,
      "currency": "PHP"
    },
    "checkoutUrl": "https://checkout.example.test/chk_8f1a2b3c4d",
    "aggregateVersion": 1
  }
}
```

## Choose the payment methods

By default the checkout page offers card, GCash and Maya. To show fewer, send `paymentMethods`. A customer who already picked GCash in your app then sees only GCash:

```json
{
  "referenceId": "BOOKING-1042",
  "amount": { "amountMinor": 39900, "currency": "PHP" },
  "successUrl": "myapp://bookings/1042/paid",
  "cancelUrl": "myapp://bookings/1042",
  "paymentMethods": ["gcash"]
}
```

Each method must be enabled for your environment; `GET /api/v1/payments/capabilities` lists them, and anything else returns `400 PAYMENT_METHOD_UNAVAILABLE`. To skip the checkout page altogether and open GCash or Maya directly, use a [wallet payment intent](/guides/payments/intents).

`successUrl` and `cancelUrl` can be HTTPS links or your app's own links. APICenter sends the customer to an app link through an HTTPS page it hosts.

## Fetch Checkout Status

- **Endpoint**: `GET /api/v1/payments/checkouts/{checkoutId}`
- **Required Scope**: `payments:checkout:read` or a broader payment read scope

```bash
curl -s https://api.apicenter.itsandbox.site/api/v1/payments/checkouts/chk_8f1a2b3c4d \
  -H "Authorization: Bearer $ACCESS_TOKEN"
```
