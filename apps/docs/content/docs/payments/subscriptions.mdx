# Subscriptions & Invoices API

Subscriptions represent recurring billing against an APICenter-managed price and customer record. Reusable payment-method setup is not currently exposed by the public API.

---

## Create Subscription

- **Endpoint**: `POST /api/v1/payments/subscriptions`
- **Required Scope**: `payments:subscriptions:write` or a broader payment write scope
- **Required Header**: `Idempotency-Key`

```bash
curl -X POST https://api-center.itsandbox.site/api/v1/payments/subscriptions \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Idempotency-Key: sub-idem-8812" \
  -H "Content-Type: application/json" \
  -d '{
    "referenceId": "SUB-TIER-PRO-001",
    "customerId": "cus_9912041",
    "priceId": "price_pro_monthly"
  }'
```
