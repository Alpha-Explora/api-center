# SMS Shared Service API

The SMS Shared Service allows product backends to dispatch transactional SMS messages without directly integrating with telecommunication providers.

---

## Service Specifications

- **Base Route**: `/api/v1/shared/sms`
- **Required Scope**: `sms:send`
- **Quota Limit**: 60 requests / minute

---

## Send Single SMS

- **Endpoint**: `POST /api/v1/shared/sms/send`

```bash
curl -X POST https://api-center.itsandbox.site/api/v1/shared/sms/send \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "to": "+639171234567",
    "message": "Your order #ORDER-991204 has been dispatched!",
    "senderId": "APICENTER"
  }'
```

### Response (`200 OK`)

```json
{
  "success": true,
  "messageId": "sms_msg_9918231a",
  "status": "queued",
  "recipient": "+639171234567"
}
```

---

## Bulk SMS Dispatch

- **Endpoint**: `POST /api/v1/shared/sms/bulk`

```bash
curl -X POST https://api-center.itsandbox.site/api/v1/shared/sms/bulk \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "recipients": ["+639171234567", "+639189876543"],
    "message": "System maintenance alert for APICenter services."
  }'
```
