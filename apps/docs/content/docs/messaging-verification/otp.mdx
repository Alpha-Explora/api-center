# OTP Verification Shared Service API

The OTP Shared Service manages the generation, anti-brute-force rate-limiting, and verification of 6-digit one-time passcodes.

---

## Generate OTP

- **Endpoint**: `POST /api/v1/shared/otp/generate`
- **Required Scope**: `otp:generate`

```bash
curl -X POST https://api-center.itsandbox.site/api/v1/shared/otp/generate \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "channel": "sms",
    "target": "+639171234567",
    "purpose": "login_verification",
    "ttlSeconds": 300
  }'
```

### Response (`200 OK`)

```json
{
  "success": true,
  "referenceId": "otp_ref_99182",
  "expiresAt": "2026-07-29T01:00:00Z"
}
```

---

## Verify OTP

- **Endpoint**: `POST /api/v1/shared/otp/verify`
- **Required Scope**: `otp:verify`

```bash
curl -X POST https://api-center.itsandbox.site/api/v1/shared/otp/verify \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "target": "+639171234567",
    "code": "849201",
    "purpose": "login_verification"
  }'
```

### Response (`200 OK`)

```json
{
  "success": true,
  "verified": true
}
```
