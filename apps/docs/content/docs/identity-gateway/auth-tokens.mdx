---
title: "Auth & Token Issuance API"
description: "Obtain service-scoped JWTs and inspect public JWKS keys."
---

The Auth API manages token issuance, refresh, and key set discovery for APICenter machine-to-machine communications.

---

## Token Endpoint

- **Endpoint**: `POST /api/v1/auth/token`

```bash
curl -X POST https://api-center.itsandbox.site/api/v1/auth/token \
  -H "Content-Type: application/json" \
  -d '{
    "serviceId": "demand-service",
    "environment": "live",
    "secret": "service-environment-secret"
  }'
```

The response includes `data.accessToken`, `data.serviceId`, `data.projectId`, and `data.tribeId`. Placement is resolved from the registry and cannot be supplied in the request.

---

## Public JWKS Endpoint

- **Endpoint**: `GET /api/v1/auth/.well-known/jwks.json`

Returns public RS256 keys for token verification by downstream services.
