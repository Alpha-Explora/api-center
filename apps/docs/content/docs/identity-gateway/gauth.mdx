# Google Auth (GAuth) Shared Service API

The GAuth Shared Service handles per-project Google OAuth 2.0 flow authorization, state HMAC signing, code-to-token exchange, token revocation, and OIDC ID Token verification.

---

## Service Specifications

- **Base Route**: `/api/v1/shared/gauth`
- **Required Header**: `Authorization: Bearer <API_KEY>`

---

## Project Registration

gauth picks the Google client from the calling project and the environment (`test` or `live`). The gateway sets both from the caller's authenticated project, so request bodies do not name a project. Each project needs an active row in `shared_gauth.oauth_apps` for every environment it uses.

- **Shared client**: a row with no `client_id` or `client_secret_ref` signs in with APICenter's Google client.
- **Own client**: a row with `client_id` and `client_secret_ref` (a Secret Manager version name) signs in with the team's Google client. gauth reads the secret from Secret Manager and caches it for up to five minutes.
- **Redirect URIs**: `redirect_uris` lists every URI gauth accepts. When a request omits `redirectUri`, gauth uses the first entry. A URI that is not listed fails with `REDIRECT_URI_NOT_REGISTERED`.

A project with no active row for the environment gets `403 OAUTH_APP_NOT_REGISTERED`.

## 1. Get Authorization URL

- **Endpoint**: `POST /api/v1/shared/gauth/oauth/authorize`

### Request Body (`GauthAuthorizeRequest`)

```json
{
  "redirectUri": "https://alphaci.com/callback",
  "scopes": ["openid", "email", "profile"],
  "accessType": "offline"
}
```

### Response (`GauthAuthorizeResponse`) — `200 OK`

```json
{
  "success": true,
  "data": {
    "authorizationUrl": "https://accounts.google.com/o/oauth2/v2/auth?client_id=...",
    "state": "eyK10a...",
    "credentialSource": "project",
    "expiresAt": "2026-07-31T23:30:00.000Z"
  }
}
```

---

## 2. Exchange Code for Tokens

`state` is required. Send the value returned by the authorize call, and send the same `redirectUri` that the authorize call used. gauth rejects a state issued for another project or environment with `INVALID_OAUTH_STATE`.


- **Endpoint**: `POST /api/v1/shared/gauth/oauth/token`

### Request Body (`GauthTokenExchangeRequest`)

```json
{
  "code": "4/0AeaY...",
  "state": "eyK10a...",
  "redirectUri": "https://alphaci.com/callback"
}
```

### Response — `200 OK`

```json
{
  "success": true,
  "data": {
    "accessToken": "ya29.a0...",
    "refreshToken": "1//04...",
    "idToken": "eyJhbGci...",
    "expiresIn": 3599,
    "tokenType": "Bearer",
    "scope": "openid email profile"
  }
}
```

---

## 3. Refresh Access Token

- **Endpoint**: `POST /api/v1/shared/gauth/oauth/token/refresh`

### Request Body

```json
{
  "refreshToken": "1//04..."
}
```

### Response — `200 OK`

```json
{
  "success": true,
  "data": {
    "accessToken": "ya29.a0NEW_ACCESS_TOKEN...",
    "refreshToken": "1//04...",
    "expiresIn": 3599,
    "tokenType": "Bearer"
  }
}
```

---

## 4. Revoke / Logout Token

- **Endpoint**: `POST /api/v1/shared/gauth/oauth/logout`

### Request Body

```json
{
  "token": "ya29.a0..."
}
```

### Response — `200 OK`

```json
{
  "success": true,
  "data": {
    "success": true
  }
}
```

---

## 5. Verify OIDC ID Token

- **Endpoint**: `POST /api/v1/shared/gauth/verify-token`

### Request Body (`GauthVerifyTokenRequest`)

```json
{
  "idToken": "eyJhbGci..."
}
```

### Response (`GauthVerifyTokenResponse`) — `200 OK`

```json
{
  "success": true,
  "data": {
    "valid": true,
    "userId": "google_user_mock_123",
    "email": "dev@alphaexplora.com",
    "emailVerified": true,
    "name": "Developer Account"
  }
}
```
