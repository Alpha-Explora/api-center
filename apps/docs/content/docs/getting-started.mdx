APICenter is the **centralized API gateway** and provider-neutral integration platform for all product backends ("consumer services") and internal tribes. 

No consumer service or tribe calls external third-party providers (like PayMongo, Twilio, or SendGrid) directly. All requests are routed, authenticated, rate-limited, and audited by APICenter.

```text
Consumer Backend (Registered Service)
       │
       ▼ (Bearer JWT / API Key)
┌─────────────────────────────────────────────────────────────┐
│                    APICenter Gateway                        │
│ ┌───────────────┐ ┌───────────────┐ ┌─────────────────────┐ │
│ │ Auth & Scopes │ │  Rate Limits  │ │ Idempotency Control │ │
│ └───────────────┘ └───────────────┘ └─────────────────────┘ │
└──────────────────────────────┬──────────────────────────────┘
                               │
      ┌────────────────────────┼────────────────────────┐
      ▼                        ▼                        ▼
┌───────────┐            ┌───────────┐            ┌───────────┐
│ Payments  │            │ SMS/Email │            │    Geo    │
│ Service   │            │ Service   │            │ Service   │
└───────────┘            └───────────┘            └───────────┘
```

## Route Namespaces

| Namespace | Endpoint Pattern | Description |
| :--- | :--- | :--- |
| **Payments** | `/api/v1/payments/*` | Provider-neutral PayMongo facade (Checkouts, Intents, Subscriptions, Refunds) |
| **Shared Services** | `/api/v1/shared/:serviceId/*` | Messaging, Email, OTP, Geo location, and utility services |
| **Tribe Proxy** | `/api/v1/tribes/:serviceId/*` | Governed inter-tribe service RPC calls |
| **Authentication** | `/api/v1/auth/*` | Machine-to-machine JWT token issuance, refresh, and JWKS |
| **Registry** | `/api/v1/registry/*` | Service self-registration and discovery |
| **Health** | `/api/v1/health/*` | Liveness and readiness probes |

## Quickstart: Making Your First Call

To call an APICenter shared service, obtain a Bearer token using the calling service's environment secret:

```bash
# 1. Fetch Machine-to-Machine JWT
TOKEN=$(curl -s -X POST http://localhost:3000/api/v1/auth/token \
  -H "Content-Type: application/json" \
  -d '{
    "serviceId": "orders-api",
    "environment": "test",
    "secret": "your-service-environment-secret"
  }' | jq -r '.data.accessToken')

# 2. Call Geo Shared Service
curl -s -X POST http://localhost:3000/api/v1/shared/geo/reverse-geocode \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"latitude":13.7563,"longitude":100.5018}'
```
