---
title: "Getting started"
description: "Get an application key and call APICenter from your backend with the server-side SDK."
---

APICenter gives your backend email, SMS, one-time codes, geocoding, Google sign-in and payments through one API and one key. Your backend calls it with the `@alpha-explora/apicenter-sdk` package.

## 1. Get a project and a key

In the APICenter console, or through your APICenter operator:

1. Create a **project** for your product. Each project has a **test** environment, and a **live** environment once it is approved.
2. Enable the capabilities you need (for example email and payments) in the environment.
3. Add an **application** for your backend, and **grant** it the actions it calls, such as `email:send` or `payments:checkout:write`.
4. Issue an **application key** for the environment. It is shown once: `ak_test_…` for test, `ak_live_…` for live.

## 2. Install the SDK

The package is hosted in restricted GitHub Packages. Your GitHub account or automation identity needs permission to read the APICenter packages.

Add this to your repository's `.npmrc`:

```ini
@alpha-explora:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=${NODE_AUTH_TOKEN}
```

Set `NODE_AUTH_TOKEN` from a secret store to a GitHub token with package read access, then install:

```bash
npm install @alpha-explora/apicenter-sdk@3.0.0
```

The SDK runs on Node 20+, Deno, Bun and edge runtimes.

## 3. Configure the key

Keep the key in your backend's environment or secret manager. Never put it in browser code, a mobile app, a checked-in `.env` file, or a `NEXT_PUBLIC_` variable.

```ini
APICENTER_API_KEY=ak_test_...
```

This is the only setting the SDK needs. The key's prefix selects the environment, and the key identifies your application. Use the `ak_live_…` key in production once your live environment is active.

## 4. Make a request

```ts
import { ApiCenter } from '@alpha-explora/apicenter-sdk';

const api = new ApiCenter();

await api.email.send({
  to: 'person@example.com',
  subject: 'Your order is ready',
  text: 'Your order is ready for pickup.',
});
```

The SDK retries network errors and server failures with the same idempotency key, so a retry never sends twice. For writes tied to a business operation, such as one checkout per order, store your own key with the operation and pass it as `{ idempotencyKey }`. Call `await api.whoami()` at startup to confirm the key's project, environment and grants.

A request for an action your application was not granted fails with a `PermissionError` (`ACTION_NOT_GRANTED`); ask for the grant rather than working around it.

## 5. Receive payment events

If you take payments, add a [webhook](/guides/events/webhooks) for an HTTPS route on your backend in each environment, and mark an order paid when `payment.checkout.paid` arrives.
