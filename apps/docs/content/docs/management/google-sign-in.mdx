---
title: "Configure Google sign-in"
description: "Set project and environment Google OAuth settings in APICenter Management and use the GAuth SDK methods."
---

Configure Google sign-in from Management. Do not create or edit GAuth database rows directly.

## Configure a project

1. Open the project in Management and choose **Test** or **Live** in the sidebar. Settings are separate for each environment, and changing live needs the project admin role.
2. Open **Capabilities** and select **Configure** next to Google sign-in. The sheet shows whether sign-in is set up, its redirect URIs, and which client it uses.
3. Enter every application redirect URI that APICenter should accept, one per line (up to 10). Use `https`; test may also use `http://localhost`.
4. Choose **Shared APICenter client**, or **Your own OAuth client** and enter its client ID and client secret.
5. If using your own client, configure it in Google Cloud with the callback URL supplied by the APICenter platform administrator. The redirect URIs entered here are the destinations APICenter allows for this project and environment.
6. Select **Save**. Saving in live asks you to confirm first. The client secret is write-only: it is never shown again, and leaving the field empty keeps the stored secret.

Switching back to the shared client deletes your stored client secret. **Remove** disables Google sign-in for that project and environment; the console names both before you confirm.

## Use GAuth from a backend

Install the SDK and configure service credentials as described in [SDK integration](/guides/sdk-usage). Then request an authorization URL:

```ts
const authorization = await api.auth.google.getAuthorizationUrl({
  scopes: ['openid', 'email', 'profile'],
  accessType: 'offline',
});

// Redirect the user's browser to authorization.authorizationUrl.
// Keep authorization.state in the user's server-side session for the callback.
```

When Google redirects back to an allowed application URL, exchange the returned code and saved state:

```ts
const tokens = await api.auth.google.exchangeCode({
  code: callback.code,
  state: session.oauthState,
});
```

The SDK also exposes `api.auth.google.refreshToken(...)` and `api.auth.google.logout(...)`. Store Google tokens only in a protected server-side store. Validate the returned OAuth state against the state saved for that user's sign-in attempt.
